Constrained decoding

You hand the provider a schema. A token that would break it cannot be emitted.

This removes malformed output. It does not make the content correct. The schema constrains shape, not membership.

The gap the schema leaves

A str field means "any string". Nothing stops a plausible invention.

Hallucinated step names

Symptom: first activity fails with unknown step 'meshing' on a solution whose step is mesh.

Cause: structured outputs constrain shape, not membership.

Mitigation: check every identifier against the real schema before anything runs, and put the valid names in the error so it becomes usable feedback.

def validate_plan(plan: Plan, solution_id: str) -> None:
    schema = SolutionSchema.for_solution(solution_id)
    for s in plan.steps:
        if s.step not in schema.steps:
            raise ValueError(f"unknown step {s.step!r}; known: {sorted(schema.steps)}")
        if not is_allowed(solution_id, s.step, s.transaction):
            raise ValueError(f"{s.step}.{s.transaction} is not allow-listed")

These checks touch no network. They run against structures loaded at startup, in microseconds, ahead of an action that costs cluster-hours.

Closed enums

Six values means a compromised model cannot name a seventh.
class RemediationKind(StrEnum):
    RETRY          = "retry"
    ADJUST_FIELD   = "adjust_field"
    RERUN_UPSTREAM = "rerun_upstream"
    SWITCH_SKILL   = "switch_skill"
    ESCALATE       = "escalate"
    ABORT          = "abort"

Six lines of Python, and it is the strongest control in the system. An enum also fails loudly on a typo, and comparisons against it are replay-safe in a way matching on prose never is.

Layer the checks, cheapest first

Each layer catches something the one before it cannot.

Layer Catches
Constrained decoding Malformed output
Model validation Wrong types, unknown fields
Semantic check Invented names, impossible order
Allow-list Actions this role may never take
Evidence-ID check Invented citations
Budget check Spend past what was authorised

Default to deny. An action absent from the allow-list is never offered to the model as an option, which is cheaper than trusting it to decline.

Runtime controls — action classes, circuit breakers, kill switches — are in Guardrails.

Takeaways

  • Constrained decoding removes malformed output. It says nothing about correctness.
  • Check identifiers against ground truth the system owns, and return the valid options as feedback.
  • A closed enum is the cheapest strong defence. Injected text cannot name what the type forbids.
  • Layer checks cheapest first. A microsecond ahead of a solver-hour is never a close call.
  • Default to deny.
